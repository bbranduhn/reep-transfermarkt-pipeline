Codebase that uses [Reep](https://reep.football/) to map the player ID from API-Football to Transfermarkt. Additionally, uses [transfermarkt-api](https://github.com/felipeall/transfermarkt-api) to get player data from 2026/2027, divided by competion. 

Download the CSV files [here](https://reep.football/data/#csv) and store inside a folder labeled `/csv`
